# protocol/migrate

The shared, stdlib-only versioned-migration runner (Postgres and SQLite). **To add a migration:** append it to your module's migration list with `Version` = previous + 1, an idempotent `Fn` (it runs inside a per-version transaction with its `schema_migrations` row insert — either both commit or neither does), and an optional cheap `Verify` post-condition; the runner handles apply-once via the version table and self-heal (a recorded-but-failing Verify re-runs) on every startup. Edge's frozen chain up to baseline 1 stays self-probing and untouched — only migrations with version > baseline may be added here. Both Core's 136-step Postgres chain and Edge's versioned migrations run through this one `Run` call, so applied-version semantics can no longer drift between the two sides.
