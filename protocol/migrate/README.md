# protocol/migrate

Verified against: 4f4870c3

The shared, stdlib-only versioned-migration runner (Postgres and SQLite). **To add a migration:** append it to your module's migration list with `Version` = previous + 1, an idempotent `Fn` (it runs inside a per-version transaction with its `schema_migrations` row insert — either both commit or neither does), and an optional cheap `Verify` post-condition; the runner handles apply-once via the version table and self-heal (a recorded-but-failing Verify re-runs, its row deleted in the re-run's own transaction, so a failed re-run leaves it recorded) on every startup. Each module's chain below its baseline is retired (`RetiredChain`: Core v184, the Edge v59): a new database is born on the generated baseline, and only migrations above it may be added. Core's Postgres chain and Edge's versioned migrations both run through this one `Run` call, so applied-version semantics cannot drift between the two sides. The package comment in `migrate.go` is the full account.
