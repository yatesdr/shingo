# test-costs: the top-level tests that cost more than 10 s run alone when the rule
# came in (2026-11-24), each with what needs its time as the test's own code and
# comments say it. Read by the repolint's test-costs rule, testcosts.go, which says
# what fires; the rule is docs/ground-rules.md's 10 s rule for a new test.
#
#   over <dir> <test> <seconds> <reason>
#
# <seconds> is the test's cost as shared/scripts/testcost reads it: the larger of
# its binary's wall and its leaves' seconds summed, the test alone in its own
# binary (`go run ./scripts/testcost -root .. -time FILE` from shared/, one run;
# the near ones twice, the larger kept). Read 2026-11-24 on the gate laptop while
# other work ran beside it, so an upper bound. The candidates were the gate-time
# baseline's tests over 10 s alone (2026-11-23, tree b5949e26); those that read
# 10 s or under on 2026-11-24 are not listed.
#
# A reason starting UNESTABLISHED is one the test's code and comments do not give.
#
# The lines only go: a test leaves when its reason is written at its func (a
# `// cost:` line in its doc comment, which the rule then requires the line here
# to go for) or when it is gone. A new test is never added here; it carries the
# marker, and scripts/check-test-cost.sh times it.
