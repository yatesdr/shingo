# serial-tests: the packages whose top-level tests must call t.Parallel() or say
# why not (`// serial: <reason>` on the line above the func), and the serial
# tests in them that predate the rule. Read by the repolint's serial-tests rule,
# serialtests.go, which says what fires.
#
#   package <dir>                a directory the rule reads (that directory only)
#   unaudited <dir> <test>       a serial top-level test there that nobody has
#                                audited yet
#
# The unaudited lines only go: a test leaves when it is audited, by calling
# t.Parallel() or by a marker naming what it shares, and a line left behind
# fails. A new serial test is never added here; it carries the marker. A package
# joins with its `package` line and one unaudited line per serial test it
# already has, which the rule's findings name.
